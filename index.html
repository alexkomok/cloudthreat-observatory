What am I looking at?

This observatory runs Cowrie, an SSH honeypot, on a public Google Cloud VM. It imitates a vulnerable server to record automated login attempts, password guesses, and commands bots use to retrieve malware.

THE PROJECT

Turning background noise
into understanding.

Internet-facing services receive automated scans and login attempts. Cowrie records activity in an isolated honeypot; a local worker enriches and aggregates the events before this page receives summary metrics.

The Threat Intel page lists up to 20 globally routable source addresses seen in repeated login attempts, with country and ASN/hosting enrichment. An IP identifies a network endpoint, not a person, and network attribution may be inaccurate. Credentials, full commands, and download URLs remain private; password rankings are aggregates of values submitted to the honeypot.
